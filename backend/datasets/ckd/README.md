# CKD Dataset Source Note

The CKD archive contains two candidate original source files:

- `original/chronic_kidney_disease.arff`
- `original/chronic_kidney_disease_full.arff`

Both files are preserved unchanged. No source file was selected, cleaned,
preprocessed, renamed, or used for training in this phase. Final dataset
selection will be made during the research/training phase after comparing the
actual contents and provenance of both candidates.
